# Contributing to T.O.R.E-Fighters

For now, the help I'm asking for is through
[GitHub Issues](https://github.com/john-overton/T.O.R.E-Fighters/issues) and
[GitHub Discussions](https://github.com/john-overton/T.O.R.E-Fighters/discussions).
Use issues for bug reports and specific requests, and discussions for ideas,
questions and general feedback.

**Pull requests will be ignored for now.** Please open an issue or start a
discussion instead.

The "Opinionated" in T.O.R.E is still very much my opinions. I'm keeping
development in my own hands while I work out what this project should be.
I'll revisit accepting pull requests once those opinions have settled and we
reach version 1.0, or sooner if I get tired of doing all the work myself.
When that changes, I'll update this page.

Before opening an issue or discussion, check whether someone has already raised
the same topic. For a bug, include what you expected, what happened, steps to
reproduce it, your operating system and the version or commit you're running.
For a suggestion, explain what you'd like to see and why it would improve the
experience.

Thanks for helping by playing, testing and telling me what you find.
